# 💫 About Me:
Hello, my name is Timotius Avaro Andrelo Putra. I'm an Information Systems student at Tarumanagara University with experience in web development, data analysis, UI/UX design, and SQL. I had an internship (field work experience) while I was in vocational high school, majoring in software engineering, in the IT division as an IT Support. My duties included setting up IP Wi-Fi PC with dedicated servers, setting up PCs, teaching computer component introductions, creating posters, and producing school promotional videos. During my university studies, I also had an internship at PT Digikidz Indonesia as an IT Coach, where I was responsible for teaching technology to students. My duties included teaching coding using Scratch and Tynker, introducing Machine Learning, teaching robotics using LEGO and VinciBot, teaching animation, preparing learning materials, guiding students through projects, evaluating students' learning progress, and managing teaching-related data and documentation.
